# ROADMAP — From Grounded Q&A Bot to an Autonomous Risk/Reward Recommendation Engine
*Fable 5 · principal-architect build plan · 2026-07-02 · builds on the nine `research/fable/` audits — this sequences the build, it does not re-diagnose.*

**One-sentence thesis:** almost everything this engine needs already exists in this repo as disconnected organs — a calibrated scorer, a pre-outcome decision journal, a Wilson-CI calibration grader, a validated backtest book, a regime feed, a screener, a news API, a proposal→phone→chokepoint spine — and the exceptional version is built by *connecting* them under one structured `DecisionCard` contract where **deterministic code owns every number and the LLM owns fusion, narrative, and ranking.** New data avenues come *after* the wiring, gated one at a time by measured lift, because the audits prove the bottleneck is not missing data — it's that the agent can't see the data the app already computes.

## 1. Target architecture (the destination)
```
                      ┌────────────────────────── LEARN ──────────────────────────┐
                      │  db/decision_journal (thesis+win% BEFORE outcome)          │
                      │  ai/journal_review.compute_calibration (Wilson-CI verdicts)│
                      │  → injected into every REASON prompt + weekly report       │
                      └────────────▲───────────────────────────────┬───────────────┘
PERCEIVE                REASON     │ outcomes        DECIDE         ▼ lessons        ACT
wide feeds → normalized  Slate Pass (LLM):           DecisionCard (Pydantic):       proposal_intake.propose_trade
features (screener,       fuse candidates × regime   numbers COPIED from            → create_phone_proposal →
 regime, get_context,     × news × memory ×          deterministic sources;         phone Approve (Face ID) →
 strategy_kinds, news,    calibration → rank,        LLM fills thesis/rank/         ExecutionService.submit
 momentum bars store)     veto, argue (SHRINK only)  risks ONLY                     (RiskEngine, kill-switch, paper)
```
**Division of labor, enforced structurally (anti-`_find_ev_bucket`):** deterministic code owns every number — `win_prob`/`ev`/CI come only from `strategy_conviction()` (validated backtest stats) or `decision_scorer.score_features()` when `sufficient=true`; entry/stop/targets from `strategy_plan()` + session-node S/R; size from a deterministic sizer. **The LLM never generates a numeric field** — the `DecisionCard` validator rejects any card whose numbers don't match their cited source. The LLM owns fusion/veto/ranking/thesis and can only *shrink or drop* a trade, never inflate it. **One intake seam, unchanged** — every surviving card becomes a `TradeCandidate` into the existing `propose_trade()` (kill-switch, sizing, RiskEngine pre-check, dedup, phone proposal, write-once journal). Do NOT build a second path to ACT. The learning loop IS the journal (every card — incl. declines — recorded, graded, fed back).

## 3. The synthesis / fusion engine
**`DecisionCard`** (new `trading/decision_card.py`, Pydantic): deterministic **copied** fields (symbol, mode, side=buy-only, entry, stop, targets, size_usd, risk_usd, r_multiple, win_prob|None, ev_pct|None, ci, conviction_basis∈{validated_backtest, calibrated_scorer, unrated}, calibration_note, source_signals, regime) + LLM **text-only** fields (thesis, key_risks, llm_rank, llm_adjustment∈{as_scored, shrink_half, veto}, evidence_refs). Validator rejects any card whose numbers don't byte-match their source.
**One Slate Pass:** (1) candidate generation (deterministic: screener presets + RVOL scanner + fired strategy checks over the S&P universe, cached/momentum-store paths — never bursts Schwab → ~15-25 shortlist; new `score_symbols([...])` batch endpoint). (2) grounding (per candidate: `get_context` facts + `strategy_signals` + top-5 news + sector RS + catalyst distance; gaps **explicitly marked** `"quote":"unavailable"`, never silently absent). (3) numbers stamped (the prod `proposals.py` precedence: validated `strategy_conviction` → scorer if `sufficient` → else `unrated`/`win_prob=None`; **Phase-0 prereq: fix `_find_ev_bucket` → None**; sizing = min(1%-risk fixed-fractional, ½-Kelly when basis=validated, vol-target)). (4) fusion (ONE heavy LLM call: system = persona + rules + calibration verdicts + lessons + founder profile; user = regime + N candidate JSONs + exposure + pending; task = rank/veto/argue; conflicts resolve deterministic-gates-first then LLM-adjudicates-in-text-with-citations, reorder/shrink/drop only). (5) validation (Pydantic + numbers-match-source + grounding check "every number in thesis appears in tool results"; failed card logged + dropped, never model-fixed). (6) emit (top-K → `propose_trade`; the rest → journal as `slate_considered` — the declines are the richest calibration data).
**Honesty end-to-end:** win_prob only ever copied from a validated/sufficient source → recorded pre-outcome → Wilson-CI graded → re-injected into the next Slate Pass ("your 60-80% bucket realizes 45%, n=12") → surfaced weekly. The number and its report card travel together forever.

## 4. Trade-vs-invest differentiator — reasoning modes (one engine, 4 modes; `mode` is first-class, set by the producing strategy or the founder in chat)
| | **day** | **swing** (default) | **position** | **invest** |
|---|---|---|---|---|
| Horizon | intraday | 2–15 days | 1–6 months | 1 yr+ |
| Data weight | RVOL, session nodes, VWAP — technicals only | dip depth, S/R, RVOL, catalyst, regime | residual momentum, sector RS, regime, breadth | fundamentals/valuation (EDGAR/Finnhub), insider clusters, moat; technicals only for entry timing |
| Risk | tight ATR, flat by close | ATR×2 + scale-out ladder | rebalance-based, drawdown bands | thesis-invalidation reviews, position % cap; wide/no stop |
| win_prob | **unrated** (no validated intraday edge) | validated per sleeve | validated (combined book) | **never shown** (no calibratable sample at this horizon) — valuation vs history + "no win% — long-horizon thesis" |
| Exit | time/stop | stop/target/time-cap | monthly rebalance | quarterly thesis review |
| Prompt | *don't build yet* | pattern-vs-plan ("does this match the validated playbook? which checks fired?") | portfolio (cross-sectional, exposure-aware) | analyst (bull/bear, valuation vs 5-yr range, what kills the thesis) |

**Opinionated calls:** ship **swing + position first** (where the validated edge lives); **day = a labeled honest shell** (the truthful answer today is "no intraday edge" — the mode exists so asking gets that answer, not silence); **invest is the genuinely new build** and the *cheapest to make feel exceptional* (almost pure LLM-fusion over EDGAR/valuation text, honesty by *withholding* win% not calibrating one). The differentiator is mostly per-mode field weights + prompt blocks + exit machinery over the same DecisionCard.

## 5. Acting on its own — autonomy, intuition, memories, rules
**Proactive loop:** 06:15 ET regime+breadth+earnings refresh → **08:45 ET daily Slate Pass** (scan→shortlist→ground→condition→score→LLM-rank→propose best K≤3 to phone, respecting `max_pending_agent_proposals=3`, seeded as a morning-brief chat thread the founder can interrogate) → every 300s (market hours) the existing strategy triggers fire event-driven candidates through the same seam via a *mini* single-candidate pass → 16:30 journal resolution + evening brief → weekly calibration report → 24h reflection now centered on `run_journal_review`.
**"Intuition" = three injected blocks every reasoning call:** (1) **track record (episodic)** — `turn_journal_context`, *already built, dead in prod*; turn it on + extend per-symbol; (2) **lessons + calibration (semantic)** — `journal_review` verdicts + curated lessons via boring FTS5 (replace inert mem0), promotion on repeated relevance + expiry on staleness; (3) **founder profile + standing rules (procedural)** — a Settings-editable block injected verbatim, *also* enforced deterministically where enforceable (prompt copy = reasoning quality, code copy = the guarantee).
**Climbing the ladder (gated on the safety audit's 4 blockers before any tap-free entry):** scoped/mandatory auth + admin-token split; paper-endpoint assertion (C1); daily-loss breaker (blocks new entries only, hard tier arms kill-switch); global daily notional cap + in-flight exposure folded in (C2). Then promotion is **per-strategy + calibration-gated**: `entry_mode=auto` only when the journal shows `well_calibrated` n≥30 AND the founder flips it (strategy-off-by-default stands). Auto fills batch into ONE summary push. Schwab stays read-only, period.

## 6. Keeping it exceptional AND honest
**Provable not vibes:** (1) a `slate_traces`/`chat_traces` SQLite table (prompt-hash, tools, results, card) ~a day (skip Langfuse-as-service for now); (2) the 30-50-case golden set (tool-routing, refusals, mechanical grounding check) nightly on serv ~$0.50; (3) the **calibration report as THE headline metric** ("agent said 62% on 40 trades; 41% resolved"); (4) a **slate-quality eval** — forward-return of the LLM's ranking vs the deterministic shortlist (if the fusion call adds nothing after a quarter, make it cheaper — honesty applies to the architecture too). **Model strategy** (provider-agnostic per ToS): two config-swappable tiers — reasoning (frontier, ~1 heavy call/day) + routine (cheap, intent/mini-passes/memory); add native tool-calling + structured output to `LLMClient` (the precondition for one Python brain replacing the three loops). **Failure modes designed against:** fabricated confidence (validator + grounding eval + H6 fix); hype-chasing (social = shrink/veto only); overfitting to recent memory (lessons carry n+expiry, Wilson CIs, capped review window); catalog bloat (every avenue has a kill date, feature count bounded by the DSR/PBO discipline); silent degradation (the ops job-runner + Schwab probe ship Phase 0.5).

**Sequencing logic:** Phases 0–2 spend ~a month and almost zero dollars turning built-but-disconnected machinery into the product — that's where the exceptional-feeling jump happens. New data (P3) comes *after* the journal/eval loop so every avenue is judged by the machine it feeds. Autonomy (P5) comes last because the audits are unambiguous that its blockers are safety engineering, not intelligence — and because a propose-mode engine with provably calibrated cards is already the life-changing unlock the mission names: the phone buzzes, the card argues honestly, the founder taps, and the record of whether it was right compounds forever.
